# Veyra 0.2.2-test.1 — общее подключение Android

Закрытая тестовая версия, ничего не опубликовано. Windows не менялась.

## Одна кнопка

- Круглый щит «Подключить всё» готовит Veyra Base · SNI / TCP и запускает сервис Android VPN вместе с локальным Telegram-мостом. Base отключает QUIC (UDP/443) для проходящего через Veyra трафика, чтобы приложения могли использовать TCP.
- «Отключить всё» останавливает эту общую сессию и её Telegram-мост.
- Если вручную выбран известный Veyra Alt 1–4, он сохраняется для следующих подключений; Telegram также включается автоматически. Для смены профиля сначала отключись.
- Неизвестная или пользовательская командная строка при обычном подключении с главного экрана заменяется Base. Открытие приложения и «Обновить» сами настройки не переписывают. Главная кнопка использует режим VPN, даже если ранее в расширенных настройках был выбран Proxy.
- При первом запуске требуется системное разрешение Android VPN. Пока оно ожидается, повторное нажатие не запускает вторую сессию.

## Telegram — одно подтверждение

1. Нажми «Подключить всё» и разреши Android VPN.
2. В одноразовом предложении нажми «Добавить», затем подтверди прокси **в самом Telegram**. Veyra не может подтвердить его за пользователя.
3. Дальше подключай и отключай всё круглым щитом. Отдельного переключателя модуля Telegram больше нет.

Адрес локального Telegram-прокси и ключ сохраняются при остановке/повторном запуске **той же установки**, пока не очищены данные приложения. Если сохранённый порт занят, запуск завершается с ошибкой, а не незаметно меняет адрес. Останови другую копию прокси и повтори подключение. При обновлении старой версии с нестандартным ранее выделенным портом может понадобиться один раз повторно добавить прокси.

Если пропустил первое предложение, кнопка «Добавить» остаётся на главной и в настройках. Она открывает сохранённую ссылку в Telegram и не служит отдельным включателем. Сообщения и медиа; звонки и Telegram Web этот мост не поддерживает. После остановки Veyra отключи локальный прокси в Telegram, если он мешает прямому подключению. Не публикуй tg://-ссылку: она содержит локальный ключ.

## Важное об установке тестового APK

Прежний ключ подписи Veyra Next 0.2.0/0.2.1 после сбоя среды недоступен. Поэтому выданный APK этой версии собирается с `-PveyraIsolatedTest`: **отдельное приложение Veyra Test**, ID `io.github.nosmokee.veyra.next.unifiedtest`, versionCode 8. Это НЕ обновление поверх Veyra Next.

- Не удаляй рабочую Veyra Next: её данные остаются в старом приложении.
- Останови старую Veyra перед запуском тестовой. Не запускай два Android VPN одновременно.
- В тестовой установке нужно впервые разрешить VPN и один раз добавить её собственный прокси в Telegram. Старое приложение и тестовое не обмениваются ключами/настройками.
- Вернуться можно, остановив Veyra Test и запустив старую Veyra Next; при необходимости выбери её прокси в Telegram.
- Для настоящего обновления поверх старой установки требуется исходный ключ подписи. Один APK не позволяет восстановить закрытый ключ. Ключи не включены в архив исходников.

## Обновить и Пинг

«Обновить» перечитывает локальное состояние и счётчики; не скачивает стратегии и не проверяет сайты. «Пинг» измеряет установку TLS/WSS-соединения с официальным Telegram-узлом через действующий локальный SOCKS. Это не ICMP и не подтверждение доставки сообщения. Скорости показываются из счётчиков Android-туннеля; без достаточных измерений отображается «—». Числа на preview подключённого состояния — фикстуры теста, не показания реального телефона.

## Ограничения и сохранённый код

Команды профилей, VPN/Proxy services, MTProto/TLS/WSS-протокол и восемь JNI-библиотек четырёх ABI сохранены из 0.2.1. Изменены оркестрация запуска, сохранение порта Telegram, ожидание разрешения VPN и подписи интерфейса. Это локальный обход, а не удалённый VPN: внешний IP не меняется. Региональные ограничения ChatGPT эта версия не снимает.

Проверки выполняются на Linux/JVM/Robolectric, не на физическом Android и не в сети пользователя. Даже успешная установка WSS не гарантирует воспроизведение YouTube или доставку сообщений в конкретной сети. Точные результаты повторной сборки — в `verification/unified-0.2.2`; старые папки verification исторические и не являются проверками нового APK.

## Сборка

JDK 17, Android SDK 34, Gradle Wrapper 8.4; интернет для зависимостей.

```sh
# Безопасная тестовая установка рядом со старой
./gradlew -PveyraPrebuiltNative -PveyraIsolatedTest assembleDebug testDebugUnitTest lintDebug

# Исходный ID — только с прежним ключом для обновления
./gradlew -PveyraPrebuiltNative -PveyraSigningStore=/путь/к/исходному/ключу assembleDebug
```

Не выдавай обычную debug-сборку с исходным ID за совместимое обновление: подпись может отличаться. Флаг prebuilt выбирает сохранённые JNI-библиотеки; полные нативные исходники и лицензии также приложены. Без флага требуются NDK 28.2.13676358 и CMake 3.22.1. Robolectric PNG: `app/build/veyra-previews`.
