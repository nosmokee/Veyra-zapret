# Veyra 1.1 Beta — Android

Бета-версия 1.1-beta.1, versionCode 9.

## Установка
1. Останови старую Veyra и другой VPN. Не удаляй старую установку без необходимости.
2. Установи Veyra-v1.1-beta.1-Android-universal.apk. Название приложения — Veyra.
   APK подписан прежним тестовым ключом Veyra Next 0.2.0/0.2.1 и может обновить эту установку.
   Отдельная историческая Veyra Test (.unifiedtest) не обновляется этим APK и может остаться рядом.
   Не запускай обе копии одновременно. Не очищай данные: там сохранён ключ локального прокси.
3. Нажми «Подключить всё» и подтверди системное разрешение VPN Android.
4. Один раз нажми «Добавить» и подтверди прокси в самом Telegram.
5. Дальше общий щит включает и выключает локальный обход и Telegram-мост вместе.

## Изменения
Жёлто-графитовая тема, скрыты входы в расширенные настройки; GitHub внизу настроек.
Крупный шрифт поддерживается, кнопка Telegram переносит текст без обрезки.
Лицензии доступны через значок информации → «Лицензии».
Base · SNI / TCP и Alt 1–4; смена профиля только после отключения.
Base отключает QUIC (UDP/443) для проходящего через Veyra трафика; DNS и другие UDP-порты остаются.
«Обновить» перечитывает локальное состояние, а не загружает профили из интернета.
«Пинг» — время TLS/WSS-соединения с официальным Telegram-узлом через локальный SOCKS;
не ICMP, не проверка доставки сообщений. Счётчики скорости отражают Android-туннель.

## Ограничения
Это локальный обход, не удалённый VPN: внешний IP не меняется, региональные ограничения ChatGPT не снимаются.
Telegram-мост: сообщения и медиа; без звонков и Telegram Web. Только официальные узлы с проверкой TLS.
Адрес/ключ сохраняются внутри одной установки. Если порт занят, останови другую копию Veyra.
После остановки Veyra отключи её прокси в Telegram, если он мешает прямому соединению.
Не публикуй tg://-ссылки и не отправляй журнал без проверки его содержимого.
Android 5.0+ (API21), четыре ABI. Физический телефон, YouTube и Telegram с учётной записью
на сети пользователя ещё требуют проверки. Не обещаем работу у каждого провайдера.

## Сборка из исходников
JDK17, Android SDK34, Gradle wrapper. Для сохранённых JNI:
    sh ./gradlew -PveyraPrebuiltNative assembleRelease testDebugUnitTest lintDebug
Выход release — неподписанный; подпиши собственным ключом через Android apksigner.
Собственный ключ не сможет обновить выданный APK. Закрытый ключ не включён.
Для полной native-сборки без флага нужны NDK28.2.13676358 и CMake3.22.1.
Исходники JNI/dependencies находятся в app/src/main/jni и app/src/main/cpp.
