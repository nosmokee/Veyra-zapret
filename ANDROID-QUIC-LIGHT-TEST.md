# Android 1.2.5: QUIC, 3 фейка

Эксперимент по сообщению пользователя: в 1.2.4 уменьшение TCP timeout с 5 до 2 секунд не уменьшило задержку; запуск обычных видео иногда 5–7 секунд. Корневая причина не установлена.

## Контролируемое сравнение
Новый отдельный профиль «YouTube QUIC · 3 фейка». По сравнению с исходным рабочим «YouTube QUIC · fake» изменено только --udp-fake 11 -> --udp-fake 3. Сохранены payload, TTL 8, TCP timeout 5 секунд и все TCP fallback-группы. Уменьшать одновременно timeout и количество фейков не стали, чтобы не смешивать факторы. Рабочий профиль не заменяется автоматически; прежние команды не меняются.

Нативный ByeDPI отправляет fake_count датаграмм перед каждой подходящей UDP-датаграммой (desync_udp). Уменьшение числа снижает этот дополнительный трафик, но влияние на реальную задержку не измерено. Меньше фейков может оказаться недостаточно для обхода DPI. Это гипотеза, не подтверждённое исправление. Фильтр UDP/443 затрагивает и другие приложения внутри VPN. Root не требуется; нативные библиотеки и Telegram не менялись.

## Установка
Отключить Veyra Wi-Fi Test, установить APK обновлением поверх 1.2.4 без удаления. Выбрать «YouTube QUIC · 3 фейка», подключиться. Принудительно остановить YouTube в настройках Android и открыть заново. На том же Wi-Fi сравнить запуск нескольких видео и 10 Shorts, затем проверить непрерывное воспроизведение 3–5 минут. Если хуже или воспроизведение ломается, отключить обход и вернуть «YouTube QUIC · fake».

## Проверки
Robolectric unit/UI tests, проверка asset-пути и сохранности оригинальных профилей; integration-tests/test_quic_light.py — 3 MiB TLS, обе fallback-группы, ровно 3 фейка + настоящая UDP-датаграмма, обратный ответ и non-443 passthrough. Проверка подписи для обновления поверх 1.2.4.

Локальные тесты не измеряют запуск YouTube, не проверяют провайдера и физическое Android-устройство. Обещания исчезновения задержки нет.

## Сборка
JDK17, SDK34, Gradle wrapper:

```sh
cd android
sh gradlew --no-daemon --max-workers=2 \
  -PveyraPrebuiltNative -PveyraIsolatedTest -PveyraWifiTest \
  -PveyraOfflineWheels=/absolute/path/to/build-tools/offline-python \
  testDebugUnitTest assembleDebug
```

Пакет io.github.nosmokee.veyra.next.wifitest, versionCode 22. Приватный тестовый ключ не входит в исходники. Для собственного релиза нужен свой signing key; самостоятельно подписанная другим ключом сборка не обновит выданный APK. Происхождение payload и ограничения: ANDROID-QUIC-FAKE-TEST.md. Windows в этой итерации не менялся.
