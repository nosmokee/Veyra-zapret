## Обновление Telegram
Быстрый выбор между двумя официальными маршрутами DC2/DC4, включая рабочий резервный IP. TLS проверяется; signed DC и MTProto-ключевой домен сохраняются. Исправление CDN203 включено. Windows-кандидат подтверждён пользователем на его ПК; тот же выбор маршрутов перенесён на Android/Linux. Это не гарантия работы всех операторов: физические Android/Linux ещё требуют проверки.

## Установка
- Android: установи APK **поверх** прежней Veyra, без удаления данных. versionCode 12 позволяет обновление с Beta 3. Название Veyra; прежние applicationId/ключ подписи сохранены. Отдельная старая Veyra Test (.unifiedtest) не заменяется. Нажми «Подключить всё», разреши Android VPN, один раз добавь прокси в Telegram. Жёлто-графитовая тема, расширенные настройки скрыты, GitHub внизу настроек. [Подробнее](android/README-VEYRA.md).
- Windows: распакуй ZIP, сохрани Veyra.exe вместе с конфигурацией/лицензиями. Останови старую копию, сохрани её папку данных. Включи обход и отдельный Telegram-мост. EXE не подписан Authenticode; это тот же проверенный пользователем кандидат. [Подробнее](windows/README.txt).
- Linux: распакуй подходящий архив, `sh ./veyra`. Python 3.9+ и Chromium/Chrome/Firefox, без sudo. Общая кнопка запускает SOCKS5/Telegram и отдельное окно браузера. Системные маршруты/firewall/основной браузер не меняются; другие приложения автоматически не переключаются. [Подробнее](linux/README.md).

Не запускай две копии одновременно. Сохранённые порт/ключ локального Telegram-прокси не меняются; не публикуй их. После остановки Veyra выключи этот прокси в Telegram, если он мешает прямому соединению.

## Ограничения и проверка
Сообщения и медиа Telegram, без звонков/Telegram Web. Не удалённый VPN, без смены IP, региональной разблокировки ChatGPT или обхода LTE-белых списков. «Обновить» перечитывает состояние; «Пинг» измеряет установку WSS, не доставку сообщений и не ICMP.

79 Android unit-тестов, 24 Kotlin protocol-теста, 36 Kotlin live-проверок; Windows C# regression/live и зашифрованные ping/pong; 39 Linux unit-тестов. На Linux первая live-матрица дала 38/39 (один некорректный ответ DC5), 10 целевых повторов и повторная полная 39/39 прошли. ARM64 не запускался. Полный честный отчёт: [TELEGRAM-FIX-REPORT.md](TELEGRAM-FIX-REPORT.md).

## Исходники и лицензии
Source code (zip)/(tar.gz) GitHub содержат исходники для обновлённого тега релиза; вручную дублировать архивы не нужно. Нативные зависимости распространяются в runtime-пакетах с лицензиями/upstream-ссылками; Windows engine.zip не включён в исходный архив. Android использует прежний development-сертификат, не новую production-подпись. Не включены личные журналы, секреты прокси и signing keystore.
