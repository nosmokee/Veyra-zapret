# Veyra 1.2

Локальное приложение для управления DPI-обходом и Telegram-прокси на Android, Windows и Linux. Не удалённый VPN: внешний IP не меняется.

## Что изменилось
- Обновлён встроенный Telegram-прокси: штатная маршрутизация WSS/H2, пул соединений и восстановление соединений.
- Одна общая кнопка включает и выключает обход вместе с Telegram.
- В разделе Telegram убрана дублирующая кнопка подключения; оставлено «Добавить прокси».
- Номер приложения — 1.2; название — Veyra. На Android сохранён янтарный интерфейс, расширенные настройки скрыты, ссылка GitHub находится в настройках.
- Сохранённые локальный ключ и порт прокси не сбрасываются.

## Установка и запуск
**Android:** установите APK поверх предыдущей Veyra, не удаляя приложение. Android7+ и 64-битный процессор обязательны; 32-битные устройства не поддерживаются этой сборкой. Нажмите «Подключить всё», подтвердите системный VPN. Один раз добавьте локальный прокси в Telegram и включите его. Если проверяли телефон через ПК, выберите именно локальный прокси Veyra, а не LAN-адрес ПК.

**Windows:** распакуйте ВЕСЬ ZIP. Нельзя переносить только EXE: рядом должны оставаться python-runtime и telegram-engine. Остановите другие копии Veyra и отдельный прокси. Запустите Veyra.exe (WinDivert требует администратора), нажмите «Подключить всё». Закрытие окна может скрыть приложение в трей; завершайте его через пункт выхода.

**Linux:** распакуйте архив своей архитектуры и запустите `./veyra`. Нужны Python3.10+, системный libcrypto (OpenSSL), Chromium/Chrome/Firefox. Root и pip при запуске готового архива не нужны. Открывается отдельное окно браузера через SOCKS5; другие приложения сами на прокси не переключаются.

После остановки Veyra выключите её прокси в Telegram, если он мешает прямому подключению.

## Приватность и ограничения
- Включены сторонние CF/H2-ретрансляторы. Их операторы могут видеть IP и метаданные соединений; это не серверы Veyra. Доступность и скорость не гарантируются.
- Telegram: сообщения и медиа; звонки этим прокси не поддерживаются.
- Внешний IP не меняется; региональные ограничения ChatGPT не снимаются. Обход физического подавления радиосигнала и всех мобильных белых списков не обещается.
- Пинг — сетевой замер, не проверка скачивания файлов. Проверяйте незакэшированные фото, видео, GIF и файлы без другого VPN.
- Перед передачей журналов проверьте их содержимое. Не публикуйте ключи, коды входа и Telegram-сессии.

## Исходники и сборка
Полные исходники и готовые offline-зависимости для переносимых пакетов доступны в Source-code.zip / Source-code.tar.gz релиза. Автоматические GitHub Source code архивы создаются из тега; в них нет комплектного Windows Python runtime и скачиваемых wheel-файлов. Не путайте исходники с установочным пакетом.

- Android: JDK17, SDK34, Python3.13 в PATH; `cd android && sh gradlew -PveyraPrebuiltNative testDebugUnitTest assembleRelease`. Для native-сборки из исходников используйте NDK/CMake проекта. Для публикации подпишите APK своим ключом; приватного ключа Veyra в репозитории нет.
- Windows: VS2022 BuildTools, .NET4.8/WPF targeting pack. См. windows/BUILD-RELEASE.txt. Комплектный runtime можно взять из переносимого Windows ZIP. Исходный Telegram-код копируется из telegram-engine в windows/telegram-engine. Зависимости: `pip download`/`pip install --target` для cp313/win_amd64 по telegram-engine/requirements.txt плюс cryptography46.0.5. Python3.13.9 embed-amd64 — python.org; runtime manifest находится в Windows-пакете. В python313._pth добавляются ../telegram-engine и ../telegram-engine/python-libs.
- Linux: `linux/BUILD-LINUX.sh` собирает ciadpi двух архитектур. Для запуска из git скопируйте telegram-engine рядом с app.py (либо оставьте в корне репозитория) и установите зависимости: `python3 -m pip install --target telegram-engine/python-libs -r telegram-engine/requirements.txt`. Готовый Linux-архив уже содержит их. Выберите соответствующий bin/ciadpi. Тесты: `cd linux && python3 -m unittest discover -s tests`.
