# Veyra 1.3 — отчёт проверок

- Android release-сборка: 102 JVM/Robolectric-теста, 0 failures/errors/skipped.
- Локальный native TCP/UDP стенд: 6 тестов; 3 MiB TLS, fallback, 3 QUIC-фейка, обратный ответ, non-443 passthrough.
- Android: проверены APK signature, совпадение сертификата с 1.2.5 тестовой линейки, версия 1.3/code23, arm64-v8a/x86_64, label Veyra, release без debuggable.
- Windows: EXE x64/.NET48 скомпилирован; встроенный движок загружен; 23 профиля разобраны; Veyra Base совпадает с ранее сработавшим YouTube 1; исходные non-YouTube правила сохранены; миграция и ручной откат/Telegram port проверены. 6 тестов рекомендации прошли.
- Linux: 42 теста прошли, включая настоящий локальный SOCKS/TCP/TLS, HTTP API, сохранение выбора, миграцию Base и сохранность секретов. Нативные статические binaries двух архитектур сохранены из оригинальных 1.2 архивов без изменений.

## Не проверялось
Физическое Android-устройство, WPF/WinDivert/Windows GUI, исполнение Linux ARM64, реальный YouTube/провайдер и измерение задержки здесь не проверялись. Автотесты не доказывают обход DPI или отсутствие буферизации. Пользователь проверял Android QUIC 3 на Wi-Fi — небольшая задержка остаётся. Его прежний standalone Windows profile1 работал; интегрированная 1.3 отдельно им ещё не подтверждена. Linux не равнозначен Android VPN: отдельный браузер через TCP SOCKS, QUIC отключён.

APK подписан сохранённым ключом тестовой линейки; обновляет Veyra Wi-Fi Test, но не оригинальную 1.2. Исходники не содержат keystore или GitHub credentials. Публичное опубликование проверяется отдельно после загрузки assets.
