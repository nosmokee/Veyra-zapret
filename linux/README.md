# Veyra 1.1-beta.3 — Linux (Beta)

Распакуй архив своей архитектуры и запусти `sh ./veyra`. Нужен Python 3.9+; отдельное окно Chromium/Chrome/Firefox открывается с локальным SOCKS5. Системный VPN, IP, маршруты и firewall не меняются. Одна кнопка запускает обход и Telegram-мост; прокси в Telegram добавляется один раз. После остановки выключи его в Telegram, если он мешает прямому соединению.

DC1–5: официальный WSS с проверкой TLS. CDN203: собственный сервер Telegram 91.105.192.100:443 через obfuscated MTProto TCP, НЕ WSS и НЕ DC2. Клиент Telegram проверяет MTProto-сервер; содержимое чатов/файлов мост не расшифровывает. Прямая TCP-доступность CDN может ограничиваться сетью. Никаких внешних ретрансляторов/смены IP/LTE-режима нет.

Сохраняй папку данных при обновлении: в ней локальный ключ и порт Telegram. Не запускай старую и новую копии одновременно. Не публикуй telegram-private.json и ссылки на прокси. Дополнительный пакет дистрибутива `python3-cryptography` ускоряет AES; без него доступен более медленный встроенный pyaes. Программа сама пакеты не устанавливает.

Результаты и пределы тестов: TEST-REPORT.md. x86_64 проверен запуском на Linux-хосте; ARM64 только архитектура/хэш, без запуска. Реальная загрузка видео из аккаунта в сети пользователя не подтверждена. GitHub: https://github.com/nosmokee/Veyra-zapret
