# Veyra 1.1 Beta — Linux

## Запуск
Выбери архив по архитектуре: `uname -m` (x86_64 или aarch64).
Распакуй архив, перейди в папку Veyra, запусти `./veyra`.
Нужны Python3.9+ и Chromium/Chrome/Firefox. Не запускай через sudo.
Если потеряны права: `chmod +x veyra bin/ciadpi`.
Панель открывается на локальном адресе, напечатанном в терминале.

«Подключить всё» запускает SOCKS5 и Telegram-мост, затем отдельное окно браузера
с прокси, отдельным профилем и отключённым QUIC/HTTP3. Окно открывает YouTube.
Если запуск браузера не удался, панель покажет предупреждение; кнопка повторного открытия остаётся.
Прокси и мост могут работать независимо от успешного открытия окна браузера.
Один раз нажми «Добавить в Telegram» и подтверди в Telegram.
Далее «Отключить всё» останавливает оба собственных сервиса.
Основной профиль браузера, системный прокси, маршруты и firewall не изменяются.
Другие приложения автоматически НЕ переключаются. Это не системный VPN.

Пять профилей: Base · SNI / TCP, Alt 1–3, Direct · диагностика.
Direct не выполняет DPI-обход. Сменить профиль можно после отключения.
«Обновить» — локальное состояние. «Пинг» — измерение TLS/WSS до Telegram через SOCKS,
не ICMP и не доказательство работы видео/доставки сообщений.

Telegram: сообщения/медиа, без звонков и Telegram Web; внешний IP не меняется.
Региональные ограничения ChatGPT не снимаются. Работа на конкретной сети не гарантирована.
Адрес/ключ Telegram сохраняются в ~/.local/share/veyra/telegram-private.json (0600).
Не удаляй этот файл, если хочешь сохранить ссылку. При занятом сохранённом порте запуск
откатывается: останови другую копию Veyra. Ключ не включается в диагностический отчёт.
Не публикуй tg://-ссылку. После остановки отключи локальный прокси в Telegram при необходимости.
Закрытие вкладки не завершает Veyra; используй кнопку завершения или Ctrl+C.
Отдельное окно браузера не закрывается принудительно: после остановки прокси в нём недоступен.

## Сборка / лицензии
Python-код не требует сборки. Чистый Python AES fallback pyaes1.6.1 включён;
при наличии cryptography используется ускоренный backend. Устанавливать pip-пакеты не требуется.
Native ByeDPI исходники в core-byedpi. BUILD-LINUX.sh требует Zig0.13.0 и собирает musl static.
Лицензии: LICENSE и LICENSES. См. THIRD-PARTY.md и TEST-REPORT.md.
GitHub: https://github.com/nosmokee/Veyra-zapret

Для сборки именно из GitHub Source code: `sh ./BUILD-LINUX.sh` с Zig0.13.0, затем `sh ./veyra`.
В исходниках нативный бинарник не включён; это не готовый установочный архив.
