# Veyra 1.1 Beta 2 — исправления Telegram

## Что изменено
Windows-вариант с новым выбором маршрутов проверен пользователем на его ПК: работа подтверждена. Тот же алгоритм перенесён на Android и Linux. Это обновлённая сборка Beta 2, заменяющая прежние файлы; отдельная Beta 3 снята с публикации.

Для DC2/DC4 сначала одновременно проверяются два маршрута к основному официальному WSS-имени: резервный IP 149.154.167.220 и обычный DNS. Используется первый успешно установивший TLS/WSS маршрут; проигравшие соединения закрываются, включая поздно завершившиеся. Не более двух попыток одновременно на сессию. Остальные официальные адреса сохранены как резервные. Кэшируется только успешный маршрут. TLS проверяет сертификат и имя сервера.

Для медиа используется тот же быстрый основной WSS-вход, но знак/номер DC и ключевой домен сохраняются. Независимый тест с анонимными MTProto-ключами и зашифрованными ping/pong подтвердил совместимость основного входа для DC2/-2 и DC4/-4. Пользовательские пакеты отправляются только победившему соединению: повторной отправки/воспроизведения запросов нет.

Сохранены исправления CDN203 из предыдущего кандидата: собственный Telegram CDN 91.105.192.100:443 через obfuscated MTProto TCP, не подмена на DC2 WSS. Это не TLS; аутентификацию MTProto-сервера выполняет клиент Telegram. Прямая TCP-доступность CDN всё ещё зависит от сети.

На Windows добавлены этапы и длительность попыток в диагностику, журнал дописывается с ограничением размера. Обычное закрытие клиентского пакета не считается поломкой прокси; обрывы внутри пакета остаются ошибками. Android сохраняет отдельный ограниченный журнал Telegram. Личные логи и ключи пользователя не публикуются.

## Фактически выполненные проверки
- Windows: опубликованный EXE байт-в-байт совпадает с частной сборкой, которую пользователь подтвердил рабочей. C# 7.3 Release x64 собран с .NET Framework 4.8 reference assemblies. Регрессионные тесты и 36 живых signed-DC/protocol nonce-проверок прошли на Linux/.NET. Через реальный C#-мост выполнены по 8 зашифрованных ping/pong с анонимными ключами на DC2/-2/4/-4. Локально WPF/WinDivert на Windows не запускались; подтверждение реального ПК предоставлено пользователем.
- Android: Gradle/Robolectric 79 тестов, 0 ошибок/падений/пропусков; дополнительный Kotlin-набор 24 теста; 36 живых signed-DC/protocol nonce-проверок. lintDebug: 0 ошибок, 61 предупреждение. Это не тест VPN/фона/видео на физическом телефоне.
- Linux: 39 unit-тестов. Первая живая матрица дала 38/39: один некорректный ответ DC5 padded. Причина не установлена. Затем тот же случай прошёл 10/10, повторная полная матрица — 39/39. Начальный сбой не скрыт; универсальная стабильность не обещается.
- Linux: идентичность ключевого домена CDN203 подтверждена независимо; шесть комбинаций протокола/DC2/-2 прошли анонимную авторизацию и по четыре зашифрованных ping/pong.
- Проверены закрытие проигравших соединений, отмена, кэш только победителя, сохранение подписанного DC, сохранение локального порта/ключа, синтетические многосессионные и фрагментированные передачи. Это не эквивалент загрузке видео из аккаунта.

## Сборки и обновление
- Android: видимое имя Veyra, versionName 1.1-beta.2-fix.1, versionCode 12 (выше Beta 3). applicationId io.github.nosmokee.veyra.next и прежний development-сертификат сохранены. Установить поверх старой Veyra, не удалять приложение/данные. Старую отдельную Veyra Test (.unifiedtest) этот APK не заменяет. Native .so неизменны.
- Windows: проверенный EXE с FileVersion 1.1.0.4 / InformationalVersion 1.1-beta.2-route.1. Имя архива Beta 2; это не другой EXE. Authenticode-подписи нет. Нативный engine.zip неизменён, его лицензии и ссылки на upstream-исходники в пакете; прежние ограничения проверки сторонних исходников сохраняются.
- Linux: runtime 1.1-beta.2-fix.1; x86_64 запускается на этом хосте, aarch64 проверен по архитектуре/хэшу, не запускался. Нативные ciadpi для каждой архитектуры неизменны. Нужен Python 3.9+ и Chromium/Chrome/Firefox. Без python3-cryptography применяется более медленный встроенный pyaes; приложение само пакеты не устанавливает.

Закрой другие копии Veyra. Сохрани папку данных Windows/Linux. На Android/Linux одна кнопка включает обход и Telegram-мост; в Windows отдельный переключатель Telegram сохранён. Прокси в Telegram добавляется один раз; при сохранённых данных порт/ключ сохраняются. После остановки Veyra отключи её прокси в Telegram, если он мешает прямому соединению. Секрет прокси не публикуй.

## Ограничения
Физический Android, Linux desktop/ARM и видео/файлы из аккаунта на этих системах в сети пользователя ещё не проверены. Выполни загрузку некэшированного видео/файла, простой и смену Wi-Fi/мобильной сети; при сбое сохрани журнал до перезапуска. Не удалённый VPN: IP не меняется. Нет звонков/Telegram Web, региональной разблокировки ChatGPT, LTE/обхода белых списков или внешнего VPS. Работоспособность при любых ограничениях оператора не гарантируется.

Исходники всех трёх приложений — стандартные Source code (zip)/(tar.gz) GitHub для обновлённого тега Beta 2. Ручных дубликатов архивов нет. Тестовые анонимные ключи, личные журналы, хранилище подписи и сгенерированные native-бинарники в исходники не включаются.
