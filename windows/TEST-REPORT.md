# Veyra1.2 — результаты проверок

## Основание выпуска
Пользователь подтвердил работу встроенного варианта, включая телефон, после установки нового APK (предыдущий проблемный журнал относился к recovery.1). Выпуск1.2 меняет интерфейс и версии; Telegram-транспорт от подтверждённого кандидата сохранён без изменений. Это отдельная пользовательская проверка, не проведённый агентом тест авторизованного Telegram.

## Проверки подтверждённого кандидата
- Android JVM/Robolectric: 89 тестов, 0 ошибок. UI/lifecycle тесты используют тестовый backend, не запускают Android CPython.
- Linux x86_64: 39 тестов, 0 ошибок. Готовый пакет: два запуска native SOCKS+Telegram, mediaDC2 req_pq/resPQ, стабильные ключ/порт и закрытие обоих портов.
- Общий адаптер: 3 запуска ×8 анонимных req_pq/resPQ (DC1/2/3/4/5, media-2/-4, CDN203), 24/24 совпадающих nonce. НЕ тест авторизованной загрузки медиа.
- Upstream core: 180 найдено, 172 успешно, 8 пропущено. GUI/update-набор не входит.
- Проверены конфликт порта, запрет второго ядра, остановка listener и редактирование ключей в диагностике; IPC stop/EOF.
- Linux Python -S: импорт offline-зависимостей и NIST AES-CTR через libcrypto.

## Проверки выпуска1.2
Результаты сборки и повторных тестов перечислены в RELEASE-CHECKS.json. Android APK подписывается прежним ключом; versionCode17, versionName1.2, API24+, arm64-v8a/x86_64. Windows: Release x64/C#7.3/.NET4.8. Комплектный Windows Python и зависимости берутся из подтверждённого кандидата.

## Ограничения
Новый1.2 APK не выполнялся агентом на физическом Android, WindowsEXE не выполнялся агентом в настоящей Windows, LinuxARM64 не выполнялся на ARM. Инструментальные Androidтесты не запускались. Самостоятельная анонимная проверка протокола не доказывает скорость и загрузку реальных медиа. Сторонние ретрансляторы не проверялись на доверие к операторам. Сеть/провайдер влияют на результат.
